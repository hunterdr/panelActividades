## 🎯 Sobre el Curso

Este repositorio contiene el código fuente, los ejercicios y los apuntes de mi camino aprendiendo desarrollo web. Está diseñado para ir **paso a paso**, explicando cada concepto de manera simple para que cualquier persona principiante pueda seguirlo sin perderse.

---

## 🛠️ ¿Qué vas a aprender?

* 🧱 **Estructura web:** Fundamentos de HTML5 y cómo organizar el contenido.
* 🎨 **Diseño y estilos:** Uso de CSS3 para dar color, diseño y adaptabilidad a las páginas.
* 📱 **Buenas prácticas:** Cómo escribir código limpio, ordenado y fácil de mantener.
